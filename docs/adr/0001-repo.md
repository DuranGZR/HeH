# ADR-0001: Ayrı `frontend/` ve `backend/` Klasör Yapısı, `pnpm` + `uv` ve İlk Gün CI Seçimi

- **Tarih**: 2026-11-24
- **Durum**: Accepted

## Bağlam ve Gerçek Problemler

HEH; React Native / Expo tabanlı bir mobil istemci ile FastAPI + Python tabanlı Türkçe NLP/URL çözümleme servisinin birlikte fakat gevşek bağlı geliştirilmesini gerektirir. Tek geliştirici temposunda bağımlılıkların deterministik kurulması, her iki tarafın birbirinin iç detayına sızmaması ve ilk günden itibaren bozuk kodun `main` dalına girmemesi kritik önemdedir.

## Kısıtlar ve Alternatifler

1. **İki ayrı Git reposu**: Kontrat senkronizasyonu ve tek PR üzerinden uçtan uca değişiklik takibi zorlaşır.
2. **Master Plan v2.1 Bölüm 04'teki `apps/mobile` + `services/api` vs kök `frontend/` + `backend/`**: Kullanıcı geliştirme ergonomisi açısından tüm mobil kodu `frontend/` altında, tüm API/domain/NLP servisini `backend/` altında doğrudan izole etmeyi tercih etti.
3. **Paket yöneticileri**: Node tarafında `npm`/`yarn` yerine çalışma alanı ve kilit dosyası hızı nedeniyle `pnpm`; Python tarafında `pip`/`poetry` yerine tek araçta sanal ortam, lockfile (`uv.lock`) ve hızlı çözümleme sunduğu için `uv` değerlendirildi.

## Karar ve Gerekçe

- Kök dizinde tek Git deposu içinde **`frontend/`** (Expo SDK 58, React Native 0.88, strict TypeScript) ve **`backend/`** (Python >=3.12, FastAPI, Pydantic v2) ayrı üst klasörler olarak konumlandırıldı.
- Frontend için `pnpm` (`node-linker=hoisted` ile React Native / Metro uyumlu `pnpm-lock.yaml`), backend için `uv` (`uv.lock`) zorunlu kılındı.
- İlk günden `.github/workflows/ci.yml` üzerinde SHA-sabitlenmiş action'larla `backend-quality`, `frontend-quality` ve birleşik `ci-gate` kontrolleri tanımlandı.

## Olumlu ve Olumsuz Sonuçlar

- **Olumlu**: Açık klasör sınırları, deterministik lockfile'lar, her PR'da otomatik format/lint/typecheck/test güvencesi.
- **Olumsuz**: Windows + `pnpm` ortamında React Native paket çözümlemesi için `.npmrc` içinde `node-linker=hoisted` ayarı gereklidir; bu ayar depoda sabitlenmiştir.

## Ölçülecek Risk / Kanıt ve Geri Alma

- **Kanıt**: `uv sync --frozen --dev`, `pnpm install --frozen-lockfile` ve 8 yerel kalite kapısının sıfır hata ile geçmesi; kırmızıdan yeşile (red-to-green) kapı doğrulaması.
- **Geri alma**: `pnpm-workspace.yaml` ve CI yol filtreleri tek PR ile güncellenebilir.
